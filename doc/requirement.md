# Prompt盲选测试平台产品需求文档

## 1. 产品概览

Prompt盲选测试平台是一个基于LMArena设计理念的在线平台，通过用户匿名投票机制评估不同prompt的效果，帮助用户发现最佳prompt。

- **核心目标**：为用户提供一个公平、客观的prompt评估平台，通过盲选测试、用户投票和AI辅助评估，帮助用户识别最有效的prompt。
- **目标用户**：Agent开发人员，业务测试人员。
- **产品价值**：简化prompt评估过程，提高AI模型使用效率，促进prompt最佳实践的分享和传播。

## 2. 核心功能

### 2.1 用户系统

| 功能   | 描述            | 用户价值            |
| ---- | ------------- | --------------- |
| 登录   | 用户登录账号，获取访问权限 | 保护用户隐私，确保投票的真实性 |
| 个人中心 | 查看个人测试历史、贡献统计 | 了解个人参与情况，查看个人影响 |

### 2.2 Prompt生成

| 功能   | 描述                 | 用户价值              |
| ---- | ------------------ | ----------------- |
| 一键生成 | 系统根据功能需求自动生成prompt | 快速创建优质prompt，提高效率 |

### 2.3 任务管理

| 功能       | 描述               | 用户价值                |
| -------- | ---------------- | ------------------- |
| 导入任务集    | 设置任务基本信息         | 创建测试任务框架，为后续测试做准备   |
| 导入prompt | 导入需要测试的prompt    | 提供测试对象，参与测试         |
| 导入测试案例   | 导入测试案例（包含多个测试问题） | 提高测试效率，尽量避免手动输入测试问题 |

### 2.4 盲选测试

| 功能    | 描述                      | 用户价值            |
| ----- | ----------------------- | --------------- |
| 随机匹配  | 系统每个问题随机使用prompt生成A/B答案 | 确保测试的公平性和客观性    |
| 大模型裁判 | 大模型选择A/B答案哪个更优          | 难抉择情况下辅助用户判断    |
| 结果统计  | 系统统计和分析投票结果             | 提供客观的prompt质量评估 |
| 结果导出  | 系统统计和分析投票结果导出             | 测试结果导出 |

### 2.5 数据分析

| 功能         | 描述                         | 用户价值                     |
| ---------- | -------------------------- | ------------------------ |
| AI辅助测试结果分析 | 利用AI分析prompt测试的详细结果，提供深度洞察 | 了解prompt的优缺点，获得AI辅助的优化建议 |
| 趋势报告       | 生成prompt使用趋势报告             | 洞察prompt发展方向，指导创作        |

## 3. 核心流程

### 3.1 用户登录流程

1. 用户访问平台首页
2. 点击登录按钮
3. 填写登录凭证
4. 提交信息并验证
5. 成功登录后进入个人中心

### 3.2 任务管理流程

1. 用户登录平台
2. 进入任务管理页面
3. 导入任务，设置任务基本信息
4. 导入需要测试的prompt，检查导入是否正确
5. 导入测试案例（包含多个测试问题），检查导入是否正确可修改
6. 若有关联测试数据，选择性导入测试数据后检查可修改
7. 系统验证并保存任务配置

### 3.3 盲选测试流程

1. 用户登录平台
2. 进入任务列表页面
3. 选择测试任务
4. 确认测试内容（任务配置、测试案例、测试数据等）
5. 对于每个问题，系统随机使用prompt生成A/B答案
6. 用户查看两个答案的效果
7. 用户选择更优的答案进行投票
8. 用户投票后AI辅助裁判给出裁判的选择与分析
9. 系统记录投票结果、AI裁判辅助结果
10. 重复步骤5-9直到用户主动结束任务或任务全部完成
11. 结束后自动展示测试结果，用户可查看每轮测试结果
12. 用户可导出任务对应的测试结果，便于存档备份

### 3.4 Prompt生成流程

1. 用户登录平台
2. 进入一键生成
3. 输入需求描述
4. 系统自动生成prompt

## 5. 技术方案

### 5.1 技术栈

- **前端**：Vue 3 + TypeScript + Vite + Tailwind CSS
- **后端**：Python + FastAPI + AI模型集成
- **存储**：结构化文件存储（JSON格式）
- **部署**：本地服务器或云服务（非容器化）

### 5.2 架构设计

- **前端**：单页应用，组件化设计
- **后端**：RESTful API，模块化设计
- **存储**：文件系统存储，JSON格式数据
- **通信**：HTTP/HTTPS协议

### 5.3 数据结构

| 数据类型   | 字段                                                                           | 描述           |
| ------ | ---------------------------------------------------------------------------- | ------------ |
| 用户     | id, username, email, password\_hash, created\_at                             | 用户基本信息       |
| Prompt | id, content, author\_id, category, tags, created\_at                         | Prompt内容和元数据 |
| 测试案例   | id, name, author\_id, questions, created\_at                                 | 测试案例信息       |
| 测试会话   | id, user\_id, test\_case\_id, created\_at, completed\_at                     | 测试会话信息       |
| 测试结果   | id, session\_id, prompt1\_id, prompt2\_id, winner\_id, question, created\_at | 测试结果信息       |
| 投票     | id, user\_id, test\_result\_id, vote, created\_at                            | 用户投票信息       |

### 5.4 核心流程

1. **用户登录流程**：访问首页 → 点击登录 → 填写凭证 → 验证 → 进入个人中心
2. **任务管理流程**：登录 → 进入任务管理 → 导入任务集 → 导入prompt → 导入测试案例 → 保存任务配置
3. **盲选测试流程**：登录 → 选择测试任务 → 确认测试数据 → 逐题测试投票 → 展示结果和分析 → 测试结果导出
4. **Prompt生成流程**：登录 → 进入一键生成 → 提问生成prompt
