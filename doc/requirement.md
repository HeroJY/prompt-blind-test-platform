# Prompt盲选测试平台产品需求文档

## 1. 产品概览

Prompt盲选测试平台是一个基于LMArena设计理念的在线平台，通过用户匿名投票机制评估不同prompt的效果，帮助用户发现最佳prompt。

- **核心目标**：为用户提供一个公平、客观的prompt评估平台，通过盲选测试、用户投票和AI辅助评估，帮助用户识别最有效的prompt。
- **目标用户**：Agent开发人员，业务测试人员。
- **产品价值**：简化prompt评估过程，提高AI模型使用效率，促进prompt最佳实践的分享和传播。

## 2. 核心功能

### 2.1 用户系统

| 功能   | 描述            | 用户价值            |
| ---- | ------------- | --------------- |
| 登录   | 用户登录账号，获取访问权限 | 保护用户隐私，确保投票的真实性 |
| 个人中心 | 查看个人测试历史、贡献统计 | 了解个人参与情况，查看个人影响 |

### 2.2 Prompt生成

| 功能       | 描述                 | 用户价值              |
| -------- | ------------------ | ----------------- |
| 一键生成     | 系统根据功能需求自动生成prompt | 快速创建优质prompt，提高效率 |

### 2.3 任务管理

| 功能       | 描述                 | 用户价值              |
| -------- | ------------------ | ----------------- |
| 新建任务 | 设置测试版本、问题数量等基本信息 | 创建测试任务框架，为后续测试做准备 |
| 上传prompt | 用户上传需要测试的prompt | 提供测试对象，参与测试 |
| 上传测试案例 | 用户选择性上传测试案例（包含多个测试问题） | 提高测试效率，尽量避免手动输入测试问题 |

### 2.4 盲选测试

| 功能   | 描述                      | 用户价值            |
| ---- | ----------------------- | --------------- |
| 随机匹配 | 系统每个问题随机使用prompt生成A/B答案 | 确保测试的公平性和客观性    |
| 大模型裁判 | 大模型选择A/B答案哪个更优 | 难抉择情况下辅助用户判断 |
| 结果统计 | 系统统计和分析投票结果             | 提供客观的prompt质量评估 |

### 2.5 数据分析

| 功能         | 描述                         | 用户价值                     |
| ---------- | -------------------------- | ------------------------ |
| AI辅助测试结果分析 | 利用AI分析prompt测试的详细结果，提供深度洞察 | 了解prompt的优缺点，获得AI辅助的优化建议 |
| 趋势报告       | 生成prompt使用趋势报告             | 洞察prompt发展方向，指导创作        |

## 3. 核心流程

### 3.1 用户登录流程

1. 用户访问平台首页
2. 点击登录按钮
3. 填写登录凭证
4. 提交信息并验证
5. 成功登录后进入个人中心

### 3.2 任务管理流程

1. 用户登录平台
2. 进入任务管理
3. 点击新建任务按钮
4. 填写任务基本信息（测试版本、任务说明、奇数个问题数量等）
5. 上传prompt
6. 选择性上传测试案例（包含多个测试问题）
7. 提交任务创建请求
8. 系统提示任务创建成功，返回任务详情页面

### 3.3 盲选测试流程

1. 用户登录平台
2. 进入任务管理
3. 选择测试任务
4. 对于每个问题，系统随机使用prompt生成A/B答案
5. 用户查看两个答案的效果
6. 用户选择更优的答案进行投票
7. 用户可选择性使用大模型裁判进行选择
8. 系统记录投票结果、大模型裁判辅助结果
9. 重复步骤4-7直到完成所有问题
10. 展示测试结果和AI辅助分析

### 3.4 Prompt生成流程

1. 用户登录平台
2. 进入一键生成
3. 输入需求描述
4. 系统自动生成prompt

## 5. 技术方案

### 5.1 技术栈

- **前端**：Vue 3 + TypeScript + Vite + Tailwind CSS
- **后端**：Python + FastAPI + AI模型集成
- **存储**：结构化文件存储（JSON格式）
- **部署**：本地服务器或云服务（非容器化）

### 5.2 架构设计

- **前端**：单页应用，组件化设计
- **后端**：RESTful API，模块化设计
- **存储**：文件系统存储，JSON格式数据
- **通信**：HTTP/HTTPS协议

### 5.3 数据结构

| 数据类型   | 字段                                                                 | 描述           |
| ------ | ------------------------------------------------------------------ | ------------ |
| 用户     | id, username, email, password\_hash, created\_at                   | 用户基本信息       |
| Prompt | id, content, author\_id, category, tags, created\_at               | Prompt内容和元数据 |
| 测试案例   | id, name, author\_id, questions, created\_at                      | 测试案例信息       |
| 测试会话   | id, user\_id, test\_case\_id, created\_at, completed\_at          | 测试会话信息       |
| 测试结果   | id, session\_id, prompt1\_id, prompt2\_id, winner\_id, question, created\_at | 测试结果信息       |
| 投票     | id, user\_id, test\_result\_id, vote, created\_at                  | 用户投票信息       |

## 6. 部署方案

### 6.1 环境要求

- **前端**：Node.js 16+，npm/yarn
- **后端**：Python 3.8+，pip
- **存储**：本地文件系统或网络存储

### 6.2 部署步骤

1. **前端部署**：
   - 安装依赖：`npm install`
   - 构建静态文件：`npm run build`
   - 部署到静态文件服务器
2. **后端部署**：
   - 创建虚拟环境：`python3 -m venv venv`
   - 激活虚拟环境：`source venv/bin/activate`
   - 安装依赖：`pip install -r requirements.txt`
   - 运行应用：`uvicorn app.main:app --host 0.0.0.0 --port 8000`
3. **存储配置**：
   - 创建数据目录结构
   - 设置适当的文件权限

## 8. 风险与挑战

| 风险    | 影响      | 应对措施               |
| ----- | ------- | ------------------ |
| 数据安全  | 用户隐私泄露  | 加密存储用户信息，限制数据访问    |
| 系统性能  | 高并发下响应慢 | 优化代码，使用缓存，合理设计文件结构 |
| 数据一致性 | 文件操作冲突  | 实现文件锁机制，确保操作原子性    |
| 用户体验  | 测试流程不流畅 | 优化界面设计，简化操作流程      |
| 数据质量  | 投票结果不客观 | 实现防作弊机制，确保投票真实性    |

## 9. 未来扩展

## 10. 验收标准

- **功能完整性**：所有核心功能正常运行

- **用户体验**：测试流程流畅，界面美观易用
- **数据准确性**：投票结果准确统计，测试结果数据更新及时
