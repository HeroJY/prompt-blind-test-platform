# Prompt盲选测试平台课题方案

## 课题目标

1. **开发一个基于LMArena设计理念的prompt盲选测试平台**，通过用户投票和AI辅助评估，帮助Agent开发人员和业务测试人员识别最有效的prompt。
2. **实现prompt的上传和一键生成功能**，简化prompt的创建和管理流程，提高用户效率。
3. **设计包含3个或奇数个问题的盲选测试流程**，确保测试的公平性和客观性。
4. **集成AI辅助分析功能**，为用户提供深度的测试结果分析和优化建议。

## 课题价值

1. **提高AI模型使用效率**：通过科学的评估机制，帮助用户快速识别最佳prompt，减少试错成本。
2. **促进prompt最佳实践传播**：通过平台的测试和分析功能，总结和分享优秀prompt的设计经验。
3. **简化prompt管理流程**：一键生成功能降低了prompt创建的门槛，使更多用户能够参与到prompt优化中。
4. **为Agent开发提供数据支持**：通过测试结果和趋势分析，为Agent开发提供数据驱动的决策依据。

## 内容简介

本课题旨在开发一个Prompt盲选测试平台，主要包含以下内容：

1. **用户系统**：实现用户登录和个人中心功能，保护用户隐私，确保投票的真实性。
2. **Prompt管理**：支持用户上传prompt和系统自动生成prompt，方便用户参与测试。
3. **盲选测试**：系统为每个问题随机生成A/B答案，用户通过投票选择更优答案，每轮测试包含3个或奇数个问题。
4. **数据分析**：利用AI分析测试结果，提供深度洞察和优化建议，生成prompt使用趋势报告。
5. **技术实现**：采用Vue 2  + Vite + Tailwind CSS前端技术栈，Python + FastAPI + AI模型集成后端技术栈，使用结构化文件存储。

## 技术方案

1. **前端技术**：
   - 框架：Vue 2 + Vite + NodeJS 12.22
   - CSS框架：Tailwind CSS
   - 状态管理：Pinia
   - 路由：Vue Router
   - HTTP客户端：Axios

2. **后端技术**：
   - 语言：Python 3.6
   - Web框架：FastAPI
   - 认证：JWT
   - AI模型集成：用于prompt生成和测试结果分析
   - 存储：结构化文件存储（JSON格式）

3. **系统架构**：
   - 前端：单页应用，组件化设计
   - 后端：RESTful API，模块化设计
   - 存储：文件系统存储，JSON格式数据
   - 通信：HTTP/HTTPS协议

4. **核心流程**：
   - 用户登录流程：访问首页 → 点击登录 → 填写凭证 → 验证 → 进入个人中心
   - 盲选测试流程：登录 → 选择测试任务 → 系统生成测试轮次 → 逐题测试投票 → 展示结果和分析
   - Prompt管理流程：登录 → 进入个人中心 → 上传或一键生成prompt

## 课题创新点

1. **盲选测试机制**：采用A/B测试模式，每个问题随机使用prompt生成答案，确保测试的公平性和客观性。
2. **奇数问题设计**：每轮测试包含3个或奇数个问题，避免平局，提高测试结果的可靠性。
3. **AI辅助功能**：集成AI模型用于prompt生成和测试结果分析，提供深度洞察和优化建议。
4. **一键生成功能**：系统根据功能需求自动生成prompt，降低用户创建prompt的门槛。
5. **文件系统存储**：采用结构化文件存储替代传统数据库，简化部署和维护。

## 填补空白

1. **Prompt评估标准化**：当前缺乏标准化的prompt评估机制，本平台通过盲选测试和AI辅助分析，建立了一套科学的评估体系。
2. **Prompt生成自动化**：现有工具多依赖用户手动创建prompt，本平台的一键生成功能填补了自动化prompt创建的空白。
3. **AI辅助分析**：结合AI技术对测试结果进行深度分析，为prompt优化提供数据支持，填补了prompt优化工具的空白。
4. **用户友好的测试流程**：设计了包含奇数问题的测试流程，提高了测试结果的可靠性，填补了测试流程设计的空白。
5. **简化部署方案**：采用文件系统存储和非容器化部署，降低了平台的部署和维护成本，填补了简易部署方案的空白。

本课题通过以上创新点和填补空白，为Agent开发人员和业务测试人员提供了一个高效、科学的prompt评估和管理平台，有助于推动AI模型在实际应用中的效果优化。
