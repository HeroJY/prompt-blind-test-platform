Prompt盲选测试平台 面向 Agent 开发与业务测试的科学评估工具

课题聚焦“如何更快找到真正有效的 Prompt”这一核心问题，借鉴 LMArena 的盲测理念， 通过匿名投票、A/B 对比、AI 辅助分析和一键生成功能，构建一套可落地、可量化、可复用的 Prompt 评估平台。

3+ 每轮测试至少包含 3 个或奇数个问题，避免平局，提高结果可靠性。
A / B 随机呈现双答案盲测结果，减少主观偏差，提升评估客观性。
AI 结合 AI 进行 Prompt 生成、结果解释与趋势分析，增强平台决策能力。

课题目标

开发一个支持 Prompt 上传、盲选测试、一键生成和 AI 结果分析的完整平台，帮助用户更高效地识别最佳 Prompt。

目标用户

面向 Agent 开发人员与业务测试人员，兼顾实验验证、流程沉淀和最佳实践传播。

Agent 开发 业务测试 产品验证

核心能力一览

用户系统、Prompt 管理、盲选投票、AI 结果分析、趋势报告、文件化存储与低成本部署，形成完整闭环。

Why It Matters

课题价值与应用意义

平台不仅解决“哪个 Prompt 更好”的判断问题，更建立起从生成、测试、分析到优化的完整方法链路。

01

提高模型使用效率

通过科学评估机制快速识别优质 Prompt，显著减少人工试错和重复比较成本。

02

沉淀最佳实践

基于盲测结果和 AI 分析，总结 Prompt 设计经验，推动团队与社区经验复用。

03

降低使用门槛

通过上传与一键生成功能，让更多非专家角色也能参与 Prompt 优化和验证。

04

支持数据驱动决策

让 Agent 开发从“经验判断”升级到“有投票证据、有趋势依据”的迭代方式。

从“凭感觉写 Prompt”转向“基于盲测持续优化 Prompt”。

本课题的真正价值，不只是做一个测试平台，而是建立一套标准化 Prompt 评估机制， 为后续 Prompt 工程、Agent 效果优化和业务落地提供基础设施。

Focus

典型使用场景

新 Prompt 方案对比、业务场景文案生成验证、Agent 工作流优化、团队 Prompt 经验沉淀与分享。

Core Workflow

平台功能与核心流程

围绕用户进入平台后的完整路径进行设计，确保测试公平、使用顺畅、结果可追踪。

用户系统

01

登录与身份验证

通过登录和个人中心机制保护用户隐私，同时确保投票行为具备真实性与可追踪性。

02

个人中心

集中展示测试历史、参与情况和个人贡献，形成用户激励与复盘入口。

Prompt 管理

01

上传 Prompt

支持用户导入待测 Prompt，快速进入评估流程，降低平台接入成本。

02

一键生成

系统根据功能需求自动生成 Prompt，帮助用户更快完成初稿构建与实验验证。

数据分析

01

结果洞察

AI 分析投票结果，输出优势、问题和优化建议，为 Prompt 迭代提供方向。

02

趋势报告

自动生成使用趋势和表现报告，辅助项目组持续跟踪 Prompt 发展与效果变化。

盲选测试流程

01

选择测试任务

用户进入平台后选择目标场景或测试任务，系统发起对应测试轮次。

02

随机生成 A/B 答案

系统针对每个问题随机调用不同 Prompt 生成结果，保证实验过程的公平与客观。

03

用户逐题投票

每轮设置 3 个或奇数个问题，通过逐题比较避免平局，提高结论稳定性。

04

展示结果与 AI 分析

系统汇总投票并生成深度分析，为 Prompt 优化提供清晰证据链。

Key Point

为什么强调奇数题设计

每轮测试固定采用 3 个或其他奇数题目，不仅简化决胜逻辑，也能在有限样本下提高测试结论的明确性和可信度。

Technology Stack

技术方案与系统架构

采用轻量、清晰、便于快速实现与维护的架构设计，兼顾功能完整性和部署成本。

前端

静态展示 + 单页应用能力

  • Vue + Vite 作为前端基础框架
  • Tailwind CSS 构建高效率界面样式
  • Pinia 管理状态，Vue Router 管理路由
  • Axios 负责与后端 API 通信
后端

模块化 API 服务

  • Python + FastAPI 提供 RESTful API
  • JWT 实现用户认证与访问控制
  • 接入 AI 模型用于生成与分析
  • 模块化拆分认证、Prompt、测试、投票等服务
存储

结构化文件系统

  • 采用 JSON 结构化文件替代传统数据库
  • 降低部署复杂度与维护门槛
  • 便于小规模课题阶段快速验证与交付
  • 适合后续按模块扩展与迁移升级
Architecture

系统架构逻辑

前端负责用户交互与测试流程编排，后端负责认证、数据处理、AI 调用与结果管理，底层以文件系统作为初期数据承载方案，通过 HTTP/HTTPS 协议完成通信。

Deployment

部署策略

前端静态文件可直接部署，后端基于 Python 虚拟环境运行，整体方案不依赖复杂容器体系，更适合课题阶段低成本推进。

Innovation

创新点与填补空白

课题的亮点不只是功能组合，而是将评估机制、自动生成与 AI 分析整合成可执行的平台方案。

01

盲选测试机制

通过 A/B 随机对比，让用户只聚焦结果质量本身，减少身份与预设偏好干扰。

02

奇数题决策设计

每轮题目数固定为 3 个或奇数个，规避平局，提高测试结论的可判定性。

03

AI 辅助生成与分析

将 AI 用于 Prompt 生成和结果解释，形成“创建 + 评估 + 优化”一体化体验。

04

轻量部署方案

利用结构化文件存储替代传统数据库，降低技术门槛，适合课题快速落地。

Gap A

填补 Prompt 评估标准化空白

当前缺乏统一、可操作的 Prompt 评估机制，本课题通过盲选与 AI 分析构建标准化流程。

Gap B

填补 Prompt 自动生成工具空白

相比依赖人工经验的现有方式，一键生成功能可帮助用户快速形成实验候选方案。

Gap C

填补低成本部署与使用空白

以结构化文件和轻量架构支撑课题推进，更适合试点验证、校内展示与小团队落地。

Roadmap

项目计划与预期实施路径

按照需求、设计、开发、测试、部署和运营的阶段递进推进，整体节奏清晰，适合课题申报展示。

第 2-3 周

系统设计

Conclusion

总结

本课题围绕 Prompt 工程中的真实痛点展开，既有创新性，也具备较强的工程可落地性。

它不是单点工具，而是一套服务于 Prompt 优化闭环的实验平台。

通过“盲测机制 + 奇数题设计 + AI 辅助分析 + 一键生成 + 轻量部署”的组合， 平台能够为 Agent 开发人员和业务测试人员提供高效、科学、低门槛的 Prompt 评估环境， 有助于推动 AI 模型在实际业务中的效果优化。
